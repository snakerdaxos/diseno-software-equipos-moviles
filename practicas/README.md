# Prácticas

Esta carpeta contiene las prácticas desarrolladas durante la asignatura **Diseño de Software para Equipos Móviles**.

Cada práctica tiene como objetivo aplicar los conceptos vistos en clase mediante el desarrollo de aplicaciones o componentes utilizando **Flutter** y **Dart**.

## Contenido

Cada práctica se organizará en una carpeta independiente con la siguiente estructura:

```
practica_01/
practica_02/
...
```

## Tecnologías

- Flutter
- Dart
- Android Studio
- Git y GitHub

# Práctica 01 - Fundamentos de Dart

## Descripción

Primera práctica de la asignatura **Diseño de Software para Equipos Móviles**.

Esta práctica se realizó utilizando la plataforma **Programiz** con el objetivo de familiarizarse con la sintaxis básica del lenguaje **Dart**, previo al desarrollo de aplicaciones con Flutter.

## Temas abordados

- Impresión en consola (`print`)
- Variables
- Tipos de datos (`int`, `double`, `num`, `String`)
- Conversión de tipos (`parse` y `toString`)
- Operaciones aritméticas
- Interpolación de cadenas
- Ejercicio de cálculo de edad

## Objetivo

Comprender los fundamentos del lenguaje Dart para aplicarlos posteriormente en el desarrollo de aplicaciones móviles con Flutter.
