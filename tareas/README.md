# Tareas

Esta carpeta almacena las tareas asignadas durante el curso de **Diseño de Software para Equipos Móviles**.

Las actividades incluyen investigaciones, ejercicios de programación y otros trabajos relacionados con el diseño y desarrollo de aplicaciones móviles utilizando **Flutter**.

## Organización

Cada tarea se almacenará en una carpeta independiente:

```
tarea_01/
tarea_02/
...
```

## Objetivo

Mantener un registro organizado de todas las tareas realizadas a lo largo del semestre.
