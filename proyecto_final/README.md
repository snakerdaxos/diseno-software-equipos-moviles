# Proyecto Final

Esta carpeta contiene el proyecto final de la asignatura **Diseño de Software para Equipos Móviles**.

El proyecto integrará los conocimientos adquiridos durante el curso mediante el desarrollo de una aplicación móvil utilizando **Flutter** y **Dart**, siguiendo principios de diseño de software, buenas prácticas de programación y control de versiones con Git.

## Contenido

Aquí se incluirán:

- Código fuente
- Recursos del proyecto
- Documentación
- Evidencias del desarrollo
- Versiones finales
